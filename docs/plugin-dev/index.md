# 插件开发

这一节会带你从零开始，写出第一个能跑的插件，然后逐步学会命令、消息、翻译、数据存储和后台任务。

BotQraft 独立运行在 QQ 机器人上，沿用 MCDReforged 那套久经考验的插件系统。如果你用过 MCDR，会很熟悉；没用过也没关系，我们会从最基础的开始。

## 从零到第一个插件

这一组会带你从一个能跑起来的小插件开始，顺手认识它需要哪些文件。准备好了？我们先从最基础的插件结构出发。

1. [基本知识](./basic.md) — 插件是什么，框架在什么时候调用你的代码。
2. [元数据](./metadata.md) — 给插件起个 ID，声明版本和依赖。
3. [插件格式](./plugin-format.md) — 选单文件、目录还是压缩包，并把插件打包出来。
4. [命令系统](./commands.md) — 弄清命令是什么、参数怎么传、用户从哪里发。
5. [SimpleCommandBuilder](./simple-command-builder.md) — 用命令路径快速注册第一条命令。
6. [第一个插件](./first-plugin.md) — 把前面学到的串起来，动手写一个 Echo，装进实例，发条消息试试。

## 收消息、回消息

读完这一组，你能让插件收到 QQ 消息，读出里面的内容，并回一条正确的消息。

7. [插件事件](./events.md) — 接上回调，知道哪些消息会触发你的代码。
8. [事件与消息格式](./message-format.md) — 从事件里取出正文、用户身份和会话信息。
9. [响应事件与回复消息](./reply.md) — 发出被动回复，并拿到操作结果。
10. [帮助消息与指令面板](./help.md) — 让命令出现在帮助列表和 QQ 指令面板里。

## 更细致的控制

读完这一组，你能搭出带分支的命令，给不同用户设权限，并用命令树处理复杂输入。

11. [命令树](./command-tree.md) — 用节点搭出更细致的命令结构。
12. [权限系统](./permissions.md) — 为命令和操作设置执行权限。
