# 什么是 BotQraft

BotQraft 是一个基于 [MCDReforged](https://github.com/MCDReforged/MCDReforged) 的、适配官方 QQ 机器人的开发框架。它继承了 MCDR 的插件开发、指令管理、权限管理等功能，使你可以像开发 MCDR 插件一样开发 BotQraft 插件，同时使用面向 QQ 的消息与事件接口。

## 为什么选择 BotQraft ？

### 原生适配官方 QQ 机器人

BotQraft 使用官方 QQ 机器人网关与 HTTP API，支持群聊和 C2C。无需额外 Adapter 、无需中间件、直接与 QQ 官方接口进行交互。

你可以很方便地使用 BotQraft 封装好的接口，与 QQ 群聊和 C2C 进行消息交互，处理事件，并实现被动回复、文本、Markdown、键盘及帮助面板等功能。

### 类 MCDR 的插件开发体验

- 傻瓜式开发：开发 BotQraft 插件甚至不需要学习**异步**（`async` `await`）编程。MCDR 原生提供了异步的事件循环和插件生命周期管理，BotQraft 继承了这些特性，使得插件开发者可以专注于业务逻辑，而无需关心底层的异步处理。
- 简化的插件管理：BotQraft 提供了简单易用的插件管理功能，使得插件的安装、卸载、启用、禁用等操作变得非常容易。
- 事件驱动的架构：BotQraft 的插件可以通过事件驱动的方式来处理消息和事件，使得插件之间的耦合度降低，增强了系统的可扩展性和灵活性。
- 丰富的命令系统：BotQraft 提供了强大的命令系统，支持多级命令、参数解析、权限控制等功能，使得插件可以轻松实现复杂的命令逻辑。你还可以直接使用 BotQraft 内置的指令模块，注册到 QQ 群里或者私聊的**机器人指令面板**中，而无需额外代码。
